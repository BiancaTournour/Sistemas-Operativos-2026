## Descripción

Este repositorio contiene los trabajos, ejercicios y casos prácticos desarrollados durante la asignatura **Sistemas Operativos — 2026**.

El objetivo principal es aplicar conceptos teóricos de sistemas operativos mediante implementaciones prácticas, haciendo especial énfasis en:

- Sistemas distribuidos.
- Comunicación y sincronización entre procesos.
- Arquitecturas distribuidas.
- Concurrencia.
- Coordinación entre componentes.
- Uso de herramientas de desarrollo.
- Implementación utilizando diferentes frameworks y tecnologías.

---

## Tecnologías y herramientas

A lo largo de los distintos casos prácticos se utilizan diferentes herramientas, lenguajes y frameworks, según los requerimientos de cada actividad.

Algunas de las tecnologías utilizadas incluyen:

- **Lenguajes de programación**
- **Frameworks**
- **Sistemas de comunicación**
- **Herramientas de desarrollo**
- **Sistemas de control de versiones**
- **Tecnologías para sistemas distribuidos**

> Las tecnologías específicas utilizadas se detallarán en cada caso práctico.

---

## Objetivos

- Comprender los principales conceptos relacionados con los sistemas operativos.
- Analizar problemas vinculados con sistemas distribuidos.
- Implementar soluciones prácticas.
- Experimentar con diferentes herramientas y frameworks.
- Comprender mecanismos de comunicación, concurrencia y sincronización.
- Aplicar buenas prácticas de desarrollo y organización de proyectos.
